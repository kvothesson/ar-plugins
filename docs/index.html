ar-plugins · gratis, abiertos, para Claude Code y Codex

Claude Code y Codex, para vivir en Argentina

Quince plugins que le dan a tu agente lo que no sabe de acá: el dólar y la inflación de hoy, cómo se saca un turno, cuánto se cobra, qué dice la ley y cómo se factura el monotributo. Con fuentes oficiales y en lenguaje llano.

Claude Code

/plugin marketplace add kvothesson/ar-plugins
/plugin install arca@ar-plugins
Dentro de Claude Code. Cambiá arca por cualquier plugin de abajo.

Codex

git clone https://github.com/kvothesson/arca ~/plugins/arca
cd ~/plugins/arca && codex
En la terminal. Cada plugin trae su AGENTS.md y Codex lo lee solo. Cambiá arca por el que quieras.

Más opciones, como cargar varios plugins a la vez, en el README.

Los plugins

Los comandos son de Claude Code. En Codex pedilo con tus palabras, por ejemplo: «¿cuánto está el blue hoy?».

Cómo están hechos

Datos en vivoLas cifras se consultan al momento: dolarapi, la API de series de datos.gob.ar y las páginas oficiales.
Fuentes a la vistaCada respuesta dice de dónde sale el dato y de qué fecha es.
AbiertosCódigo abierto, un repo por plugin. Si algo está mal, el plugin reportar abre el issue por vos.
